COURSE MATCH - PART C STARTER

This is a fresh starter based on the agreed project structure. It is not
a backup of the code on your Mac. Matching and agent features are not built yet.

OPEN AND RUN ON MAC
1. Extract the ZIP and open the Course-MatchAgent folder in VS Code.
2. Open Terminal > New Terminal in that folder.
3. Run these commands individually:

   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python -m pytest
   python -m uvicorn backend.main:app --reload --port 8000

4. Leave the server running and visit:
   http://127.0.0.1:8000
   http://127.0.0.1:8000/health
5. Press Control+C in the terminal to stop the server.

WINDOWS
Create the environment with: py -m venv .venv
Activate in PowerShell with: .\.venv\Scripts\Activate.ps1
Then use the same python commands as above.

ENVIRONMENT FILE
No .env or API key is included in the ZIP. Copy .env.example to .env locally
before the first commit. On Mac: cp .env.example .env
The key can stay blank for this skeleton. Only add the professor's key
yourself when model features need it. Never paste keys into AI chats.
.gitignore excludes .env and .venv. Keep .env.example committed.
Claude Code's Read deny rules are in .claude/settings.json.
The documented start command explicitly uses port 8000; changing PORT alone
does not override that command.

GITHUB
A ZIP uploaded to GitHub stays an archive; GitHub does not unpack it.
Extract first. Prefer committing and pushing the extracted project with Git,
which includes dotfiles automatically and respects .gitignore.
In a fresh extracted project, run:

   git init
   git check-ignore -v .env .venv/
   git status
   git add .
   git diff --cached --name-only

Check that no .env, .venv or secret is staged. Then:

   git commit -m "Project skeleton"
   git branch -M main

Create an empty GitHub repository without generating a README, license or
gitignore. Run the remote-add and push commands GitHub shows for an existing
repository. Do not copy this starter over an existing working project.
